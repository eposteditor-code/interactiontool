# InteractionTool Automated Test Plan

This iteration adds unit tests around the deterministic calculator engine.

Covered:
- PTO reducing annual work time
- Four-day workweeks
- Fully remote jobs
- Commute time and committed time
- Direct job costs
- Signing bonus separation
- Break-even salary parity
- Signing bonus excluded from break-even
- Office-day negotiation effect
- PTO negotiation effect
- Validation rules
- Decision-pattern classification

Run locally:

```bash
npm install
npm test
```

Optional watch mode:

```bash
npm run test:watch
```

Next recommended test expansion:
- percentage-based bonus/retirement plans once added
- localStorage persistence
- React interaction tests for the Negotiation Lab
