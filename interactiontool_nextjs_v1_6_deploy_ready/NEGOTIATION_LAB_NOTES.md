# InteractionTool V1.3 — React Negotiation Lab

The results screen now includes a fully interactive Negotiation Lab.

## Live controls
- Base salary
- Office days/week
- PTO days/year
- Expected annual bonus
- Employer retirement value

Every change reruns the deterministic calculator immediately.

## Live outputs
- Break-even status
- Break-even salary
- Current scenario gap
- Scenario effective value/hour
- Current-job effective value/hour
- Scenario committed time
- Three best modeled negotiation paths

## Important modeling rule
Changing bonus or retirement currently treats them as fixed annual dollar amounts. Percentage-based compensation plans can be added later as a separate model type.
